# Umair Umar — Portfolio

Vercel-ready static portfolio built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Poppins + Inter)

## Files
- `index.html` — main portfolio
- `style.css` — responsive styling and animations
- `script.js` — navigation, scroll animation, active menu and contact mailto
- `assets/profile.png` — supplied profile image
- `assets/profile-full.jpg` — supplied full-body image
- `assets/Umair-Umar-CV.pdf` — supplied CV

## Deploy to Vercel
1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Push the folder to GitHub, or import the folder into Vercel.
4. No build command is required. It is a static site.

## Before publishing
Add real GitHub/LinkedIn/project URLs when available. The current project cards intentionally do not invent external project URLs.
